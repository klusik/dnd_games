# DnD Games

Repozitář pro více nezávislých kampaní stolních RPG. Stabilní systém a kanonické herní checkpointy jsou ve větvi `main`, vývoj infrastruktury ve větvi `develop`.

Herní stav se ukládá samostatně pro každou kampaň. Obsah veřejného repozitáře není soukromý a může obsahovat spoilery, proto se nezveřejňují neodhalené DM podklady ani osobní údaje bez samostatného rozhodnutí.
